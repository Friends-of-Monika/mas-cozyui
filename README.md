## 🌟 Features

* Everything [ComfyUI](https://github.com/Iniquitatis/DDLCComfyUI) provides:
  - Multiple beautiful built-in UI themes
  - In-game theme configurator
  - HiDPI theme support

* ...and even more!
  - [Online theme editor](https://cozy.mon.icu) &mdash; pick your own colors, shapes, and even fonts
  - Easier installation/uninstallation of the submod &mdash; all files are bundled under `Submods\CozyUI` folder
  - Full support of updates via [Submod Updater](https://github.com/Booplicate/MAS-Submods-SubmodUpdaterPlugin/)
  - Submod maintenance and support for future Monika After Story updates

* ...but:
  - DDLC support removed entirely &mdash; CozyUI is a *Monika After Story* submod only

## ❓ Installing

> [!WARNING]
> This submod is **incompatible** with ComfyUI! <br/>
> In order to install CozyUI, you will need to uninstall ComfyUI entirely.

1. Go to [the latest release page](https://github.com/Friends-of-Monika/mas-cozyui/releases/latest)
   and scroll to Assets section.
2. Download `cozyui-VERSION.zip` file.
3. Drag and drop `Submods` folder from it into your `game` folder.
4. You're all set!

## 💅 Custom themes

> [!WARNING]
> Custom ComfyUI themes (.arc files) are *incompatible* with CozyUI (which uses .zip)

CozyUI comes with built-in themes, but you can easily come up with your own! The simplest way to do that is to
use [the online theme editor](https://cozy.mon.icu). Once you're satisfied with your new theme, click 'Theme > Export theme (.zip)' &mdash; you can choose either default variant or HiDPI, or both.

After your theme renders, drop the downloaded .zip file into `Submods\CozyUI\themes`, restart the game, and
your new theme will show up in submod settings section (use the slider to select.)
